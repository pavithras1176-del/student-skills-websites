# Student Skills Website

A responsive static website built with HTML, CSS, and vanilla JavaScript. The uploaded Student Skills logo is included in `assets/`.

## Files
- `index.html` — page structure and website content
- `style.css` — brand colours, responsive layout, and styling
- `script.js` — mobile navigation, active section link, contact-form email draft
- `assets/student-skills-logo.jpg` — supplied logo image

## Run in VS Code
1. Extract `student-skills-website.zip` to a folder.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `student_skills_website` folder.
4. Open `index.html`.
5. Recommended: install the **Live Server** extension by Ritwick Dey.
6. Right-click `index.html` and choose **Open with Live Server**.
7. Your default browser will open the website. Save edits in VS Code; Live Server refreshes the page.

You can also open `index.html` directly in a browser, but Live Server is more convenient during development.

## Notes
- The site uses the Google Fonts CDN for Plus Jakarta Sans. If you are offline, it falls back to Arial.
- The contact form is a demo. It prepares a message in the visitor's default email app; it does not send data to a server. A real production contact form needs a backend or form service.
- Career resource links currently point to the contact section as placeholders. Replace them with verified resource URLs or dedicated pages before publishing.
- The site does not include login, database, course enrolment, or admin features.
